# F-Tapper

Windows-программа и прошивка для платы **Digispark (ATtiny85)**.

Плата подключается как обычная USB-клавиатура и сама нажимает выбранную клавишу с неровным «живым» ритмом. Программа на компьютере включает и выключает этот тапер, меняет клавишу и скорость, прошивает плату.

## Для чего

Нужен, когда одну и ту же клавишу надо нажимать долго и регулярно, а руками неудобно:

- держать действие в игре или приложении, пока ты занят другим;
- повторять одну клавишу с паузами, похожими на ручные нажатия, а не на метроном;
- управлять этим с боковой кнопки мыши или горячей клавиши, не открывая окно каждый раз.

Тапы идут **с платы**, а не из софта на ПК: компьютер видит обычную HID-клавиатуру. Программа только командует плате (вкл/выкл, клавиша, скорость) и прошивает её.

Используй там, где это разрешено правилами сервиса или игры.

## Что умеет

### Плата

- Жмёт одну выбранную клавишу, пока тапер включён.
- Паузы между нажатиями неровные: чаще около середины диапазона, редкие короткие и длинные, плюс доли миллисекунды.
- Диод на плате вспыхивает только в момент тапа.
- При подключении — три вспышки старта, затем ждёт команд с ПК.

### Программа на Windows

**Окно и трей**

- Компактное окно: связь с платой, статус «что делать», кружок тапера.
- Свернуть — в трей; крестик — выход. Двойной клик по значку трея открывает окно.
- Иконка трея показывает, на связи ли плата (зелёный / красный).

**Включение тапера**

- Клик по кружку «тапер» в окне.
- Или команда: боковая кнопка мыши Back, Forward, обе, либо своя клавиша / сочетание.
- После смены команды окно отпускает фокус, чтобы следующий тап не попал в программу.

**Настройки**

- **Клавиша** — что тапает плата (задаётся с клавиатуры в поле).
- **Скорость 1–10** — диапазон пауз: на 1 чаще 209–322 мс, на 10 чаще 49–282 мс; между ними плавно.
- Маячок у ползунка моргает в том же ритме, который уйдёт на плату.
- Настройки сохраняются и при связи с платой уходят на неё сразу.

**Прошивка из программы**

- В exe уже лежат прошивка и инструмент записи.
- Перед записью сравнивается прошивка в программе с той, что на плате: если та же — не шьёт.
- Перед прошивкой тапер выключается.
- Драйвер загрузчика не ставится при каждом запуске: только если нужен для «Прошить», потом можно снять кнопкой «Снять драйвер».

**Права администратора**

- При запуске Windows спрашивает UAC.
- Без прав админа боковая кнопка мыши часто не ловится в игре, запущенной от администратора; команда на плату и прошивка тоже обычно не проходят.

Программу можно запускать с обычного диска и с сетевой папки.

## Какая плата нужна

| Подходит | Не подходит |
|---|---|
| Digispark на ATtiny85, загрузчик micronucleus, такт 16.5 МГц | Digispark Pro |
| Клоны такой же платы | Обычный Arduino |
| | Платы без micronucleus |

## Быстрый старт

1. Скачай `F-Tapper.exe` из релизов или собери: `.\build.ps1`.
2. Запусти (UAC → Да).
3. Воткни Digispark → **Настройки → Прошить**, следуй строке статуса (выдерни USB / воткни обратно).
4. Выбери клавишу и скорость, включи тапер кружком или боковой кнопкой мыши.

Если драйвер загрузчика не встал из программы:  
https://github.com/digistump/DigistumpArduino/releases/tag/1.6.7 — файл `Digistump.Drivers.zip`, на 64-bit Windows запусти `DPinst64.exe`, затем снова «Прошить».

Пока драйвер загрузчика установлен, включённый тапер может подтормаживать ПК — после прошивки его можно снять в настройках.

## Сборка

Нужен .NET Framework 4.x (обычно уже есть в Windows).

```powershell
.\build.ps1
```

Получится `F-Tapper.exe` с иконкой, манифестом admin и встроенной прошивкой.

Пересобрать прошивку (если менял `.ino` или библиотеку):

```powershell
.\build.ps1 -Firmware
```

Нужны `arduino-cli` и ядро Digistump (`digistump:avr`).
